Need help?

Nothing happens when I install

Check that Tampermonkey is enabled. Chrome-based browsers may also need Allow User Scripts turned on.

I see code instead of an installer

Download the script and open it in a text editor. Copy all its text. In Tampermonkey’s dashboard, choose Create a new script, replace the sample code with the copied text and save.

Which browsers can I use?

Desktop Firefox, Chrome, Edge, Brave and Opera/GX are the intended browsers. Not all have been live-tested. Safari is unverified; mobile is not supported.

Two translator controls appear

Disable older copies of the script or the separate translator extension, then refresh Twitch.

Where does my text go?

Text is sent to your selected translation provider. AI and DeepL may require an API key and charge for usage. Enter keys only in the translator’s settings.
