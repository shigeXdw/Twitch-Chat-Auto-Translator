Installer didn’t open?

Make sure Tampermonkey is installed and enabled. This page must be hosted over HTTPS for the normal install flow.

Alternatively, download the script, open Tampermonkey’s dashboard, choose Create a new script, replace the editor contents with the downloaded file’s text and save.

On supported Chrome-based browsers, Tampermonkey may also require the Allow User Scripts permission. Permission help ↗

Before you install

This page cannot install extensions or desktop apps silently. Your browser asks for confirmation. Chat text goes to your selected translation provider; AI and DeepL may require an API key and incur charges. Google’s no-key service is unofficial. Audio is not included in this version.

Updating an existing Tampermonkey copy keeps its settings. Settings from the standalone extension are separate.
